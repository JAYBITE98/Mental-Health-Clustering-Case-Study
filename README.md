## 📋 Overview
This project applies unsupervised machine learning to the **2016 OSMI Mental Health in Tech Survey** dataset. The goal is to identify distinct employee segments (clusters) based on their attitudes towards mental health, fear of consequences, and perceived workplace support. This analysis provides actionable insights for **Human Resources (HR) departments** to design targeted, effective mental health interventions.

## ✨ Key Findings
*   **4 distinct employee clusters** were identified using K-Means clustering.
*   **31.4% of employees (Cluster 0)** show high fear and low comfort discussing mental health—representing the highest-risk group needing immediate intervention.
*   **Principal Component Analysis (PCA)** revealed the main drivers of employee segmentation: *Psychological Safety* and *Organizational Support*.
